# Subagents

Agents selected from [agency-agents](https://github.com/msitarzewski/agency-agents)
(MIT License, © AgentLand Contributors) (9 of ~250) plus one written for this repo, because they match OlivEye's pipeline.
Each file keeps the original text plus an "OlivEye project context" section.

| Agent | When |
|---|---|
| `spatial-data-engineer` | SIGPAC / openEO ETL |
| `gis-qa-engineer` | Validate geodata outputs (CRS, geometries, areas) |
| `spatial-data-scientist` | Features from indices and climate |
| `statistician` | Validation design with few campaigns |
| `model-qa` | Audit models and metrics before publishing |
| `code-reviewer` | Review changes before commit |
| `web-gis-developer` | Phase 5 web map |
| `oliveye-auditor` | **Audit** against OlivEye rules: credits, CRS, leakage, repo hygiene (written for this repo) |
| `reality-checker` | **Audit** gate before closing a phase or deploying: evidence or NEEDS WORK |
| `accessibility-auditor` | **Audit** the web for WCAG (Phase 5) |

Not included: marketing, sales, game development, mobile, blockchain, etc. — unrelated to the project.
