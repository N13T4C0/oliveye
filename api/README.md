# OlivEye API

Read-only FastAPI service, deployed as a Vercel project whose **Root Directory is `api/`**
(ADR 0005). It only reads the small JSON files in [`data/`](data/), so it starts fast and the CDN
caches every response (`Cache-Control: s-maxage=86400`).

| File | Role |
|---|---|
| `app.py` | Vercel entrypoint (top-level `app`) |
| `oliveye_api.py` | the application (typed; tests in `tests/test_api.py`) |
| `requirements.txt` | runtime dependencies for Vercel (FastAPI only) |
| `data/*.json` | published data, regenerated by `scripts/export_api_data.py` |

```bash
# Run locally (docs at http://127.0.0.1:8000/docs)
uv run uvicorn app:app --app-dir api --reload

# Regenerate the data after a new model run
uv run python scripts/export_api_data.py --results-dir ../oliveye-results \
    --model-run data/processed/model_run --forecast data/processed/forecast_2026-27
```

| Endpoint | Returns |
|---|---|
| `GET /health` | status |
| `GET /municipalities?province=23` | municipalities (INE names), SIGPAC olive hectares, whether processed |
| `GET /municipalities/{province}/{municipality}/indices` | monthly NDVI / NDMI 2016–2026 (outliers removed causally) |
| `GET /provinces/{province}/production` | final production (and how it was obtained), aforo and model prediction per campaign |
| `GET /models/summary` | leave-one-campaign-out scores on like-for-like rows |
| `GET /models/errors` | OlivEye vs aforo signed % error per province and campaign |
| `GET /forecast` | dated 2026/27 forecast with its 80 % interval |
| `GET /map/municipalities` | GeoJSON (EPSG:4326): measured olive area per municipality with seasonal indices per campaign |

Province codes are INE codes (23 Jaén, 18 Granada); municipality codes are the Catastro codes
SIGPAC uses.
