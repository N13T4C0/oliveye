# Curated sources

Small hand-curated reference tables, each row with its source URL, for values that are not
available as machine-readable files. Generated data never lives here (see `data/README.md`).

| File | Content |
|---|---|
| `aforo_press_releases.csv` | Junta aforo per province for campaigns whose PDF could not be found (2016/17, 2019/20, 2020/21). 2015/16, 2017/18 and 2018/19 are still missing. From 2021/22 on, the aforo comes from the PDFs (`aforo_table` job). |
